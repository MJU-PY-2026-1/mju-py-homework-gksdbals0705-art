# 🐍 [2026-01] 나만의 파이썬 소프트웨어 개발 프로젝트

## 1. 시나리오 제목
비만 관리 시스템
<br>


## 2. 시나리오 (5~10줄)
* 이 프로그램은 사용자의 BMI지수를 계산하고, 목표치를 정해주어 사용자의 건강 관리를 보조하는 시스템입니다.
* 이 프로그램은 각 사용자에 맞춘 건강 관리 보조가 목표입니다. 이를 위해 우선, 사용자의 이름, 나이, 성별을 입력 받아 정보를 저장합니다. 이후 사용자의 몸무게, 키를 입력받아 BMI지수를 계산합니다. BMI지수를 토대로 사용자가 저체중, 정상, 과체중, 비만 중 어디에 속하는지 알려줍니다. 사용자에게 권장 BMI(18.5 ~ 22.9)와 사용자의 성별과 나이대의 사람들의 평균 값을 제공하여 사용자가 목표 BMI를 정할 수 있도록 도와줍니다.(만약, 사용자가 23살 여자인 경우, 20대 여성의 평균 BMI 지수를 보여줍니다.). 이제 사용자가 목표하는 BMI를 입력 받을 시간입니다. 해당 BMI에 도달하기 위해 얼마만큼의 체중 감량 혹은 증량이 필요한지 계산해줍니다. 이제부터 꾸준함이 중요합니다! 사용자는 매주 본인이 정해둔 시간에 프로그램에 체중을 입력합니다. 사용자가 몸무게를 새로 입력하면 기존에 입력 됐던 몸무게와 비교하여 사용자의 증량, 감량 여부를 확인시켜 줍니다. 이후 "00님!! 지난번보다 00KG 감량하셨네요 대단해요! 앞으로 00KG만 더 감량(증량)하면 목표 달성입니다. 화이팅!" 만약 사용자가 목표한 것과 반대로 증량(감량)이 이뤄졌다면 위로의 멘트와 함께 컨설팅을 해줍니다. "00님, 이번주는 체중의 변동이 있네요.. 괜찮습니다! 우리 다음주에는 식단관리와 운동을 더 열심히 해서 목표 체중까지 달려갑시다!!". 사용자가 드디어 목표 체중에 도달 했습니다.  "OO님!! 목표 달성입니다. 축하드립니다! 앞으로도 우리 프로그램과 함께 체중 관리를 해봐요. 고생하셨습니다!" 라는 문구를 띄어주어 사용자가 단기적으로 목표를 이루는 것이 아닌, 꾸준하게 건강 관리를 하도록 돕는 것이 이 프로그램의 궁극적인 목표입니다.


## 3. 예상 기능 및 메뉴
1. 사용자 정보 등록
2. BMI 계산과 저체중, 정상, 과체중, 비만으로 분류
3. 권장 BMI와 사용자의 성별과 나이대를 고려한 BMI 평균 값을 제공하여 목표 BMI값 설정
4. 목표 BMI까지 필요한 체중 변화량 계산
5. 매주 사용자의 변화량 입력 및 상황에 맞춘 격려 및 컨설팅
0. 시스템 종료

## 🟦 [1차 과제: V1.0] 시나리오 기획
- 사용자의 이름, 나이, 성별, 몸무게, 키를 입력받아 정보를 저장하고 BMI지수를 출력합니다.
- 사용자의 그룹(나이,성별 기준)의 평균BMI와 정상 BMI를 모두 알려주어 목표 BMI지수를 입력하도록 돕습니다. 목표 BMI까지의 체중을 얼마나 감량(증량)해야 하는지 출력합니다.
- 매주 입력받은 체중을 통해, 사용자의 진행도와 위로의 멘트를 출력합니다.
- 
### **🤖 AI 파트너십 과정**

 1. **내용 1 :  프로그래밍 주제에 따른 시나이로 기획**
    * **프롬프트 요약:** ""파이썬으로 BMI 관리 프로그램을 만들고 싶어. 입문자의 단계에서 어떤식으로 프로그램을 구성하면 좋을까?.""
    * **적용 내용:** BMI 관리 시스템이라는 큰 틀만 잡고, 어떤 식으로 프로그램을 구성할지 막막했는데 AI가 조언을 통해 단순히 사용자의 BMI를 측정하는 것을 넘어서 비만도를 출력하면 좋겠다는 아이디어를 얻었다. 이를 토대로 건강관리를 보조하는 시스템으로 활용하겠다는 목표를 세웠다.
      
 2. **내용 2 : 건강 관리 보조 시스템에 필요한 내용**
    * **프롬프트 요약:** "BMI지수를 이용해 건강 관리 보조 시스템을 만들기 위해선 어떤 항목을 넣는게 좋을까?"
    * **적용 내용:** 목표를 사용자가 정하게 한다는  AI의 말에 영감을 얻어, 정상 BMI와 사용자 그룹의 평균 BMI를 사용자에게 제공하여 직접 목표 BMI를 설정하도록 설정했다. 또한 AI의 조언을 토대로, 사용자의 기존 체중과 비교하여 앞으로의 방향성을 컨설팅 해주는 프로그램으로 설계하게 됐다.

## 🟩 [2차 과제: V1.0] 입출력 + 리스트 + 조건문 - 향후 작성 예정
### **✨2차 과제 내용:**
(예시)
  * 이번 과제는 용사 등록 및 정밀 진단 시스템 구현으로, 사용자로부터 데이터를 입력받아 리스트에 저장하고, 가중치 연산을 통해 결과값을 도출하는 시스템을 구축하는 것입니다. 특히 `if-elif` 조건문과 `and/or` 논리 연산자를 활용하여 상황에 맞는 등급과 특별 칭호를 부여하는 지능형 로직을 완성해야 합니다.
  * input()으로 용사의 이름, 체력, 마력, 공격력을 입력받아 리스트에 저장.
  * 가중치 공식을 적용하여 종합 전투력 산출: (체력 * 0.7) + (마력 * 0.5) + (공격력 * 1.8).
  * if-elif-else를 사용하여 S등급부터 F등급까지 5단계 등급 판정 로직 추가.
  * and 연산자를 활용하여 '전설의 대마법사' 등 특별 칭호 부여 기능 구현.
    
### **🤖 AI 파트너십 과정**
(예시) 
1. **내용 1: 길드 매니저 컨셉 및 로직 도출**
    * **프롬프트 요약:** "내가 길드 매니저가 되어 용사를 관리하는 프로그램을 만들 거야. 1학년 수준에서 리스트와 조건문을 활용해 등급을 매기는 재미있는 로직을 짜줘."
    * **적용 내용:** AI가 제안한 '가중치 전투력 산출' 방식과 'S등급이면서 마력이 높으면 대마법사 칭호 부여'라는 복합 조건 아이디어를 실제 코드에 반영함.

2. **내용 2: 효율적인 리스트 활용법 자문**
    * **프롬프트 요약:** "파이썬 기초 문법 단계(리스트 → 조건문 → 반복문 → 함수/딕셔너리)에 맞춰, '용사 길드 관리자' 컨셉의 프로그램이 어떻게 발전할 수 있을지 4단계 기능 확장 로드맵을 제안해줘."
    * **적용 내용:** 단순 입출력을 넘어, **'기초 정보 입력 및 리스트 저장(1차) → 전투 등급 판독기 구현(2차) → 무한 메뉴 시스템 구축(3차) → 딕셔너리를 활용한 다중 캐릭터 관리(4차)'**로 이어지는 논리적인 확장 로드맵을 확립함.
    
### **🛠️ Troubleshooting & 기술 회고:**
(예시) 
1. **문제 1: 숫자를 입력했는데 계산이 안 되는 현상 (TypeError)**
    * **원인:** `input()`으로 받은 데이터는 기본적으로 '글자'라서 숫자와 곱셈 연산이 불가능했음.
    * **해결:** `int()`와 `float()` 함수를 사용하여 입력값을 숫자로 바꾸는 '형변환' 마법을 부려 해결함.
2. **문제 2: 조건문 뒤에 자꾸 생기는 빨간 줄 (SyntaxError)**
    * **원인:** `if`와 `elif` 조건식 끝에 마법의 기호인 `:`(콜론)을 자꾸 빠뜨려서 발생함.
    * **해결:** 파이썬의 모든 조건문과 반복문 끝에는 항상 땡땡(`:`)이 들어가야 한다는 규칙을 학습하고 수정함.
